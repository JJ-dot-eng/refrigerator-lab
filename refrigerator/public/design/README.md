# 1도어 냉장고 시뮬레이션용 설계 자료

이 자료는 가상 운전 시뮬레이터의 설계 입력이다. 압축기 또는 실제 제품의 측정 성능표가 아니다.

## 냉동 사이클

CoolProp 8.0.0으로 R600a 정상상태 증기압축 사이클을 실제 계산했다. 증발온도 -25..0 °C, 응축온도 30..65 °C, 각각 5 K 간격의 48개 점이다. 과열 5 K, 과냉 3 K, 등엔트로피 효율 0.60, 모터 효율 0.85, 질량유량 0.00045 kg/s를 가정했다. 앱 기준점은 증발 -15 °C / 응축 40 °C다.

압축기 입구 h1은 과열 증기, h2는 효율을 반영한 토출, h3은 과냉 액, h4=h3은 등엔탈피 팽창이다. 냉각량은 m(h1-h4), 축동력은 m(h2-h1), 전력은 축동력/0.85다. 냉매 응축 방열량 m(h2-h3)에 별도의 모터 손실을 더해야 총 외부 방열량이 된다. 모든 점에서 냉매 측 에너지수지 오차가 1e-8 W 미만임을 확인했다.

`cycle-table.json`은 앱 보간용이고 `r600a-cycle-grid.json`은 상세 SI 값이다. 모델에는 압축기 맵, 충전량, 압력손실, 냉매 과도 분포, 착상·제상 해석이 포함되지 않는다. 고정 질량유량은 설계 가정이며 실제 특정 압축기와의 일치를 뜻하지 않는다.

## 기구

CadQuery가 `one-door-120l.step` 및 `one-door-120l.stl`을 생성한다. 캐비닛과 문 외형은 550 × 580 × 1000 mm, 최소 측벽 단열은 50 mm, 문 두께는 60 mm다. 후면 응축기 개념 형상은 17.5 mm 추가 돌출한다. 내함 유효 공간 가정 137.7 L에서 하단 기계실 돌출 17.82 L를 빼면 119.88 L, 선반 3개의 재료 부피를 빼면 117.71 L다. 작은 피팅과 증발기도 공간을 차지하며 공인 수납용량 시험치는 아니다.

STEP은 부품 위치·외피를 표현한 개념 조립체다. 기계실 돌출 형상은 내부 금지영역을 표시하는 솔리드라 압축기와 겹친다. 제조용 케이스 벽·배관·기밀 구조·체결부 완성 모델로 해석하면 안 된다.

현재 설치된 CadQuery Python 환경은 `import cadquery`만 실행해도 정상 출력 후 종료 시 Windows 오류 -1073740940(힙 손상)을 반환한다. 모델 파일 생성과 에너지수지 assertion은 완료됐으며, 모델 파일 검증은 독립 FreeCAD 로더로 수행한다. 이는 생성 코드의 계산 오류와 구분되는 설치 환경 문제이며 종료 성공으로 숨기지 않았다.

## 배선과 PCB

WireViz YAML에서 실제 HTML/SVG/PNG 연결도를 생성했다. 핀 정의는 `design-metadata.json`에 있다. 인버터는 가상 UART 명령 장치이며 3.3 V 참조 전압, GND, TX/RX, ENABLE만 표현한다. 전력 인버터 회로는 없다. 전선 길이는 배치에 따른 예시 가정으로 3D 경로에서 자동 산출한 값은 아니다.

`virtual-io-carrier.kicad_pcb`는 95 × 60 mm의 실제 KiCad 연결 기판 파일이다. J0 가상 제어기 포트와 J1..J6 커넥터 사이의 배선을 담는다. MCU, 전압조정기, NTC 분압 저항, EEPROM IC, 전력소자 등은 실장하지 않은 I/O 연결 참조다. 따라서 완성된 냉장고 메인 PCB로 표기하지 않는다. 라이브러리와 DRC 보고서를 동봉한다.
